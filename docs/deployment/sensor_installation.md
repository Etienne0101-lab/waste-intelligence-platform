# Sensor Installation Guide

## Prerequisites

- ESP32 sensor nodes
- Ultrasonic sensor and load-cell mount kit
- Gateway coverage validation
- Battery or power supply verification

## Installation steps

1. Mount the bin hardware securely and away from high-vibration zones.
2. Verify correct alignment for the ultrasonic sensor.
3. Calibrate the load cell using a known reference mass.
4. Validate connectivity to a mesh gateway or MQTT broker.
5. Record bin metadata such as location, facility assignment, and cluster ID.

## Calibration

Follow a repeatable calibration process:
- zero offset calibration
- empty-bin baseline reading
- known-weight validation
- operational drift review
